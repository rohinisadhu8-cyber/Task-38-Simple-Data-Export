
# Task 38 - Simple Data Export

## Project Overview
This project demonstrates how to clean and export a retail sales dataset using Python and Pandas.

The processed dataset is exported into CSV and Excel formats for easy storage and further analysis.

## Objective
- Import retail sales data.
- Remove duplicate records.
- Handle missing values.
- Convert date columns.
- Calculate total sales.
- Export data into CSV and Excel formats.

## Technologies Used
- Python
- Pandas
- Openpyxl
- Visual Studio Code

## Dataset Information
The dataset contains 10 retail sales records.

Columns:
- Order_ID
- Date
- Product
- Category
- Quantity
- Unit_Price
- Region

## Project Structure

Task_38_Simple_Data_Export/
- dataset/
  - retail_sales.csv
- output/
  - cleaned_sales.csv

- export_data.py
- requirements.txt
- README.md

## Data Processing
1. Read the CSV dataset using Pandas.
2. Removed duplicate records.
3. Handled missing values.
4. Converted the Date column.
5. Calculated Total_Sales.
6. Exported the cleaned data into CSV and XLSX files.
7. Verified both output files.

## Installation

Install the required libraries:

pip install pandas openpyxl

## How to Run

Run the following command:

python export_data.py
